# PathFACT Offline Evaluation

PathFACT provides CPU-only evaluation of shortest-path predictions generated by external language models.

## 1. Evaluation capabilities

- Historical VSP scoring reproduces the verified G08/G09 evaluation policy.
- Strict shortest-path validation independently computes the graph optimum.
- Model inference and GPU training are external to PathFACT.

## 2. Evaluate saved predictions

Run:

    pathfact evaluate saved --input predictions.jsonl --output-dir evaluation_output --expected-records 300

The input must be JSONL containing one evaluation record per line.
The expected-records argument is optional and checks dataset completeness.
The output directory must not already exist.

## 3. Required input fields

- case_id or production_case_id: case identifier (duplicates are not currently rejected).
- topology: weighted adjacency-list representation.
- node_pair: source and destination nodes.
- gold_cost: reference shortest-path cost.
- predicted_path: previously extracted candidate path.

## 4. Output files

- per_case.jsonl: independently recomputed historical VSP results.
- summary.json: aggregate scoring and completion statistics.

All supplied records remain in the evaluation denominator, including failed and truncated requests.

## 5. Historical VSP scoring

Historical VSP evaluates five conditions:

1. A nonempty candidate path containing integer nodes.
2. Correct source and destination.
3. No repeated nodes.
4. Every consecutive edge exists in the topology.
5. Predicted path cost matches the recorded gold_cost.

Cost comparison uses absolute tolerance 1e-9 and zero relative tolerance.
The historical scorer trusts the supplied gold_cost; it does not independently recompute the graph optimum.

Failure categories, in priority order:

1. no_path_extracted
2. wrong_source_or_destination
3. repeated_nodes
4. nonexistent_edge
5. continuous_but_suboptimal
6. valid

Completion status does not automatically determine VSP correctness.
Length-truncated responses are scored if they contain an extracted path.
Historical inference errors are evaluated with an empty candidate path.

## 6. Raw-response extraction

PathFACT provides the following Python API:

    from pathfact.evaluation import extract_historical_message
    message = {"content": "Answer: [0, 1, 2]"}
    result = extract_historical_message(message)
    print(result["predicted_path"])

The historical extractor prioritises final answer content.
A separate reasoning trace is not searched for an alternative answer.
Raw-content fallback applies only when no path and no reasoning are present.

This API does not perform inference or handle failed model requests.
Raw-message extraction is not currently exposed as a CLI command.

## 7. Independent shortest-path verification

PathFACT also provides an independent solver-based validator.

Example command:

    pathfact path verify --graph-file graph.json --source 0 --destination 2 --candidate "[0,1,2]"

The graph file must contain a weighted adjacency-list JSON object.

Unlike historical VSP, strict validation independently computes the shortest-path cost.
It reports path feasibility, optimality, path cost, optimal cost, and optimal-path hop bounds.

Historical VSP and strict validation are distinct evaluation policies.
Their results must be identified separately in research reports.

## 8. Verified historical reproducibility

The internal frozen regression suite has verified:

- Historical VSP scoring for 1,779 Student and Teacher records.
- Historical VSP scoring for 10,338 G08/G09 evaluation records across 16 runs.
- Historical answer extraction across the same 10,338 evaluation records.
- End-to-end CLI reproduction of G08 Balanced-300 Base task-only evaluation.
- The G08 Base task-only result of 42 VSP-valid predictions out of 300.

These checks reproduce completed historical evaluations.
They do not represent newly generated model predictions or training experiments.

Historical research files are optional regression references.
They are not required for the public CPU-only environment.

## 9. Current limitations

- Model inference and GPU training are external to PathFACT.
- The evaluate saved CLI requires an already-extracted predicted_path.
- Historical VSP trusts the supplied gold_cost.
- The saved-path CLI does not currently reject duplicate case identifiers.
- Raw-message extraction is available through Python, not through the CLI.
- The framework does not reproduce model checkpoints or inference outputs automatically.

Researchers should distinguish historical compatibility from independent solver verification.
